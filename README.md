# 感知工程知识库

面向机器人感知工程的个人知识库，覆盖感知算法、传感器与几何、多传感器融合、机器人系统及工程部署。知识库的长期目标、技术路线和内容边界见[知识库定位](知识库定位.md)。

## 建议阅读路径

从基础几何和单传感器感知开始，再进入 3D 感知、融合与机器人系统；部署、数据评估和具身智能可按当前问题穿插学习。
