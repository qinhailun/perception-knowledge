# 感知工程知识库

面向感知算法、工程实践与系统设计的个人知识库，当前以机器人感知为主要应用背景。知识库的长期目标、技术路线和内容边界见[知识库定位](知识库定位.md)。

## 阅读路径

可从基础几何进入感知算法，再按需要学习工程实践、系统设计和平台适配。
